# Felipe de Carvalho Figueiredo — Academic Profile

An editorial, research-oriented personal website built with Next.js and designed
for static deployment on Vercel Hobby.

## Local development

```bash
pnpm install
pnpm dev
```

Run the production check with:

```bash
pnpm build
```

## Verified profile content

Identity, profile facts, research interests, experiences, and concept-stage
projects live in `lib/site.ts`. Keep claims conservative and change a content
item to `status: "draft"` whenever it is not ready to publish.

Before expanding the profile, verify:

- exact institutional role or employer wording;
- dates and host institution for international rotations;
- public Lattes, ORCID, GitHub, or institutional profile URLs;
- publication metadata and DOI;
- current ECFMG/USMLE status;
- project stage and validation status.

Only confirmed public links belong in `siteProfile.links` and `sameAs` structured
data.

## Notes

Notes live in `content/notes/*.md` with validated frontmatter:

```yaml
title: "A descriptive title"
summary: "A concise search and index description of at least 30 characters."
date: "2026-07-25"
language: "en"
status: "draft"
```

Drafts are excluded from the index, sitemap, and static route generation. The
build fails when frontmatter is incomplete or malformed.

## Assets

- Portrait: `public/images/felipe-portrait.jpg`
- Favicon/manifest icon: `public/icon.svg`
- Open Graph image: generated by `app/opengraph-image.tsx`

The CV route intentionally returns 404 and is excluded from navigation and the
sitemap until a complete, verified CV is available.

## Search launch checklist

1. Add and verify `https://felipef.com` in Google Search Console.
2. Submit `https://felipef.com/sitemap.xml`.
3. Inspect the homepage, Portuguese profile, and each published note.
4. Keep the same full name and site URL on confirmed professional profiles.
5. Re-run structured-data, accessibility, and performance checks after material
   content updates.
